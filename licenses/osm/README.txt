The included .osm retains the selected major streets, water, parks and landmarks,
their referenced nodes and original attribution metadata. Building geometry is
supplied separately by attributed premade model authors.

The game's Colombo layout is an authored, compact racing interpretation, not
a street-navigation map. Coast/lake/park/street relationships informed authoring.
The reference dataset and derived map-context data are provided under ODbL.
The runtime game requires no map server or network connection.
