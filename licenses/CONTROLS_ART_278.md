# Loading controls artwork

controller.svg, keyboard.svg, wheel.svg and anchors.json were supplied by the project owner on 2026-11-06 for integration and distribution with Leo Racer 2.7.8. The supplied pack describes transparent 360 × 240 vector artwork without external dependencies.

Original file hashes are recorded in assets/ui/controls/provenance.json. The files are used as static textures; live binding text and animated highlights are separate Godot overlays. No CC0 claim is made for these user-supplied assets.
