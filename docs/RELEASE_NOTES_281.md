# Leo Racer 2.8.1 release candidate

Extract the complete portable archive to a fresh folder and start LeoRacer.exe. Play Compatibility.cmd selects OpenGL. The offline build contains 21 cars and four circuits, including Kandy Lake.

The Handling setting under Game Logic applies at race start or restart. Easy lowers normal and boosted top speeds by 30%, softens acceleration, and smooths human steering. Assisted blends Easy and Standard. The race uses one setting for both local players and all AI opponents. Records are grouped by handling preset.

Draw Distance under Graphics controls how far ahead scenery loads. The Wennappuwa road collision fix addresses the false impact near 65% of the lap. This build also includes the rebuilt Kandy scenery pack.
