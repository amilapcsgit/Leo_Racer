# Image provenance

- `promotional-key-art-ai.png`: AI-generated promotional illustration created for the 2.5 release on 27 October 2026. It depicts a stylized Sri Lankan lakeside race and is not a gameplay screenshot or visual-acceptance reference.
- `bigster.png`, `mclaren-765lt.png`, `wrangler.png`: untouched twenty-car candidate garage captures, taken with the same presentation/material code used by the release. The later camera change affects speed-driven chase distance, not garage rendering.
- `astra.png`, `colombo.png`, `kandy.png`: untouched 1920×1080 Forward+ Medium captures from the final native executable with only its diagnostic probe replaced in a disposable copy. Racers are paused at fixed viewpoints to allow scenery to settle. Game rendering and vehicle resources are unchanged.
- `split-screen.png`: untouched capture from the final executable's two-player camera regression suite, showing independent reverse views.

Original measurement logs and diagnostic instrumentation hashes are supplied in the release evidence ZIP. Contact clips in that ZIP come from controlled development fixtures; their README explains the deliberately remote spawn and expected missed-checkpoint hint.
