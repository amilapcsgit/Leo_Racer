# Leo Racer 1.8.0 — Colombo City

Race the new **5.5 km Colombo City Grand Prix**, or choose the original **Astra Lotus Coast**. Both tracks support single player and local vertical split screen: six racers, three laps.

- New waterfront, Fort-style streets, commercial district and Lotus / Beira surroundings, with Lotus Tower, Galle Face Green and the custom pavilion retained.
- Licensed premade city buildings, warm daylight, readable district signs and scenery streamed around both players.
- Separate **GameAssets** folders and a small core package. Keep the entire extracted folder together; launch **LeoRacer.exe**, or **Play Compatibility.cmd** for OpenGL. No .NET SDK or network connection is required.
- Track selection, route-driven checkpoints / AI / recovery, and named rankings separated by track and course revision. Existing settings, original-track records and legacy bests are preserved.
- Existing vehicles, six drivers, input customization, approved Bigster size and wheel pivots retained.

Download the **Setup** EXE for installation, or the **win64 ZIP** for portable use. Checksums are included.

This build uses Godot's checked template, which passes the offline shutdown checks. The optimized-template diagnostic exit issue is recorded in `docs/COLOMBO_CITY_VALIDATION.md`; further look-and-feel work is planned for the next iteration. The published 1.7.0 release remains unchanged.
