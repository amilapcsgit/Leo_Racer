Leo Racer local2player — UNPUBLISHED DEVELOPMENT BUILD

Extract this entire folder and run Leo Racer.exe. No installer, .NET SDK, network or database server is needed.
Stable Leo Racer 1.6 remains separate. This build does not replace its installation.

2 PLAYER MODE: Player 1 left, Player 2 right; six racers, three laps.
Use one keyboard plus a controller/wheel, or two separate controllers. Only one keyboard player is allowed.
CONTROLS: choose a device for each player, rebind actions and calibrate raw wheel axes/pedals.
Identical controllers require explicit selection and a button confirmation. Disconnect pauses everyone.
RANKINGS: local named race/lap records, separate mode and speed classes; old 1.6 best is shown separately.
Pause → Change Car targets the chosen player and marks the race ineligible for records.
All six drivers are available inside Duster and Bigster. Bigster retains its approved size and corrected tire pivots.

Logitech Formula Force EX physical compatibility remains unverified (hardware unavailable).
Wheel force feedback, Colombo HDRI and the wider collision redesign are outside this milestone.
