**Leo Racer** is a Windows arcade racer set on stylized Sri Lankan roads. Charge a drift, catch a slipstream, and spend your nitro on the next straight. Take on five AI rivals or share the screen with a friend. Pick a driver, pick a ride, and chase a better lap.

Prefer a ZIP? **[Portable v2.3.2](https://github.com/amilapcsgit/Leo_Racer/releases/download/v2.3.2/LeoRacer-2.3.2-win64.zip)** includes three tracks and 16 cars. <details>
<summary><strong>Upgrading, Compatibility mode &amp; checksums</strong></summary>

- Existing settings, control profiles, records, and user-added cars keep their locations.
- Replaced modified files are backed up under `ContentBackups`. Deselecting installed content preserves it.
- Use `Play Compatibility.cmd` if Vulkan is unavailable. Forward+ is recommended; Compatibility uses simpler effects and may show frame spikes.
- [Release notes, SHA256 checksums, evidence, and earlier versions](https://github.com/amilapcsgit/Leo_Racer/releases). Previous releases remain available for rollback.

<details>
<summary><strong>Remapping, shared keyboards &amp; Reduced Motion</strong></summary>

**Race Setup → Controls** saves per-player bindings and calibration for keyboard, mapped controllers, and raw joystick/wheel axes. Each pad or wheel belongs to one player. Shared-keyboard presets use complementary WASD/arrow layouts; P2 uses Numpad 1/2/3/0 for the new feature buttons.

Existing assignments take precedence over conflicting new defaults. Bigster's Action 2 is unassigned. An assigned-device disconnect pauses both players until reassignment or retirement.

**Reduced Motion** disables camera kicks, roll, shake, recovery distortion, and decorative UI movement while retaining useful visual feedback. Physical wheel compatibility remains unverified; force feedback is not included.

</details>

## Build &amp; create

<details>
<summary><strong>Developer setup, content tools &amp; the track SDK</strong></summary>

The released game uses **Godot 4.7.2 .NET**, GDScript gameplay, and C# presentation/SQLite bridges. Source for the published release is tagged **v2.3.2**; the camera and vehicle feature work is on **orbitcamera**.

Start with [setup and pinned dependencies](docs/COLOMBO_SETUP.md). With the required original asset archives, run:

```powershell
& ".\Setup Colombo.cmd" -AssetArchives "C:\assets\AI"
& ".\Open Colombo in Godot.cmd"
```

Build compatible content independently:

```powershell
./tools/check_modularity.ps1 -Integration
./tools/build_content.ps1 -Target vehicle -Id duster
./tools/build_content.ps1 -Target track -Id community_example
./tools/build_content.ps1 -Target sdk
```

Vehicle and track targets do not export a new executable. See the [SDK requirements](sdk/README.md) before importing third-party models.
